POS Data Pipeline — PostgreSQL, Python & Power BI

Personal Project · 2026

An end-to-end data engineering project for a multi-branch retail store: synthetic POS data flows through an incremental ETL into a star-schema warehouse and is reported in a Power BI dashboard.

  • Incremental ETL in Python using watermarks and idempotent upserts, run in a single transaction so a failed load leaves no partial data.
  • Star-schema warehouse (one fact table, four dimensions) with a Type 2 slowly changing dimension for product price history, plus reconciliation checks between layers.
  • Power BI dashboard with DAX measures for revenue, gross margin, transactions, and average basket by month, branch, and product category.
